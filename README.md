# Tugas POLSRI 2026 - IT-FESTIVAL 2026

Single Page Application untuk prototype website **IT-FESTIVAL 2026** Jurusan Manajemen Informatika, Politeknik Negeri Sriwijaya.

## Fitur

- Landing page neo-brutalist retro pixel art.
- Katalog 9 event: kompetisi, pelatihan, dan seminar.
- Login dan register lokal berbasis `localStorage`.
- Dashboard peserta.
- Form pendaftaran solo dan team.
- Konfirmasi data.
- E-ticket dengan ID registrasi unik.
- Responsive untuk desktop dan mobile.
